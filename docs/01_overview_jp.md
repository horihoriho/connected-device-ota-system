# CONCEPT

## Overview

### Background

Connected Deviceでは、サーバとの通信を利用した遠隔状態監視、遠隔制御、ソフトウェア更新などの機能が利用されている。IoTデバイス、産業機器、医療機器など、ネットワークに接続されるデバイスにおいて、これらを実現するConnected Systemは重要な構成要素となる。

これらを実現するため、本プロジェクトではデバイス・サーバ間の双方向通信、非同期の状態・イベント通知、リモートソフトウェアアップデートを主要な技術要素として扱う。

本プロジェクトでは、自身のコネクテッドシステム、通信プロトコルの基礎知識、およびシステム開発経験を活かし、C++/Linux環境で実践的な実装を行うことで、Connected Deviceに関する技術理解の向上と実装スキルの定着を目指す。

### Use Case

Connected Deviceとして以下の主要機能を実装する。

1. **Device Monitoring**  
   デバイスが自身の状態を定期的、またはイベント発生時にサーバへ通知し、管理側からデバイスの最新状態を確認できる。

2. **Remote Control**  
   サーバからデバイスへ制御コマンドを送信し、デバイスはコマンドを実行して処理結果を応答する。

3. **Software Update**  
   サーバからデバイスへソフトウェア更新を指示し、デバイスは更新パッケージの取得・検証・更新適用を行い、その結果を通知する。

### Scope

デバイスおよびサーバを以下の範囲で実装する。

#### Device

- Linux上で動作するC++アプリケーション
- TCP/IPによるRemote Commandの受信と応答
- MQTTによるデバイス状態・イベントの通知
- OTAパッケージの取得・検証・更新適用
- 通信エラー、タイムアウト等の基本的な異常系処理

#### Server

- Linux上で動作する簡易的なDevice Management System
- TCP/IPによるRemote Commandの送信とResponseの受信
- MQTTによるデバイス状態・イベントの取得
- OTAパッケージの配信

#### Out of Scope

TLS、デバイス認証、OTAパッケージの署名検証などのセキュリティ機能は初期実装のスコープ対象外とする。ただし、将来的にこれらの機能を追加できることを考慮した設計とする。
